APLIKASI RENTAL PLAYSTATION - UJK

Cara install:
1. Ekstrak folder ini ke htdocs XAMPP, contoh:
   C:\xampp\htdocs\ujk-praktek
2. Buka phpMyAdmin.
3. Import file database.sql.
   File ini sudah membuat database bernama ujk, tabel users, tabel dataps, akun admin, dan contoh data.
4. Jalankan di browser:
   http://localhost/ujk-praktek/login.php
